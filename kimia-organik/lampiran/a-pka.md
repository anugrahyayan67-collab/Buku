# Lampiran A Tabel pKa

Nilai pKa dalam air pada 25 °C, dibulatkan. Nilai di bawah 0 dan di atas 14 tidak dapat diukur langsung di dalam air dan berasal dari pengukuran dalam pelarut lain atau perhitungan; nilai-nilai itu hanya perkiraan dan dapat berbeda beberapa satuan di antara sumber. Asam ditulis di kolom kiri dengan proton yang lepas, basa konjugatnya di kolom kanan.

| Asam | pKa | Basa konjugat |
|---|---|---|
| HI | −10 | I⁻ |
| HBr | −9 | Br⁻ |
| HCl | −7 | Cl⁻ |
| H₂SO₄ | −3 | HSO₄⁻ |
| H₃O⁺ | −1,7 | H₂O |
| CF₃COOH | 0,2 | CF₃COO⁻ |
| HF | 3,2 | F⁻ |
| HCOOH | 3,75 | HCOO⁻ |
| C₆H₅COOH | 4,20 | C₆H₅COO⁻ |
| CH₃COOH | 4,76 | CH₃COO⁻ |
| H₂CO₃ | 6,35 | HCO₃⁻ |
| HCN | 9,2 | CN⁻ |
| NH₄⁺ | 9,25 | NH₃ |
| C₆H₅OH | 10,0 | C₆H₅O⁻ |
| CH₃NH₃⁺ | 10,6 | CH₃NH₂ |
| H₂O | 15,7 | OH⁻ |
| CH₃OH | 15,5 | CH₃O⁻ |
| CH₃CH₂OH | 16 | CH₃CH₂O⁻ |
| (CH₃)₃COH | 18 | (CH₃)₃CO⁻ |
| CH₃COCH₃ | 19 | CH₂COCH₃⁻ |
| HC≡CH | 25 | HC≡C⁻ |
| NH₃ | 38 | NH₂⁻ |
| CH₂=CH₂ | 44 | CH₂=CH⁻ |
| CH₄ | 50 | CH₃⁻ |

Makin kecil pKa, makin kuat asamnya, dan makin lemah basa konjugatnya. Sebuah reaksi asam–basa berlangsung ke arah pembentukan asam yang lebih lemah (pKa lebih besar). Bab 3 menjelaskan cara memakai tabel ini.
