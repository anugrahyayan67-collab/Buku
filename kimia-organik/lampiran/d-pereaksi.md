## D.3 Lambang dan istilah dalam persamaan reaksi

| Lambang | Arti |
|---|---|
| → | reaksi berlangsung ke kanan |
| ⇌ | kesetimbangan |
| ↔ | struktur resonansi (bukan reaksi) |
| ⇒ | retrosintesis: "dapat dibuat dari" |
| Δ | dipanaskan |
| *hν* | cahaya (penyinaran) |
| [O], [H] | oksidasi, reduksi (pereaksi tidak dirinci) |
| 1. ... 2. ... | langkah berurutan; pereaksi kedua ditambahkan setelah reaksi pertama selesai |
| (l), (g), (aq) | cair, gas, larutan air |
| ‡ | keadaan transisi |
| δ+, δ− | muatan parsial |
