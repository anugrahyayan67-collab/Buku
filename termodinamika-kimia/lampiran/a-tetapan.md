# Lampiran A Tetapan dan Faktor Konversi

Nilai-nilai berikut adalah nilai CODATA 2018. Sejak redefinisi SI tahun 2019, tetapan Avogadro, tetapan Boltzmann, muatan elementer, tetapan Planck, dan laju cahaya mempunyai nilai **tepat**; tetapan gas *R* dan tetapan Faraday *F* diturunkan darinya.

| Tetapan | Lambang | Nilai |
|---|---|---|
| Tetapan Avogadro | $N_\text{A}$ | $6{,}022\,140\,76 \times 10^{23}$ mol⁻¹ (tepat) |
| Tetapan Boltzmann | *k* | $1{,}380\,649 \times 10^{-23}$ J K⁻¹ (tepat) |
| Tetapan gas | $R = N_\text{A}k$ | 8,314 462 6 J K⁻¹ mol⁻¹ |
| | | 0,082 057 4 L atm K⁻¹ mol⁻¹ |
| | | 0,083 144 6 L bar K⁻¹ mol⁻¹ |
| Muatan elementer | *e* | $1{,}602\,176\,634 \times 10^{-19}$ C (tepat) |
| Tetapan Faraday | $F = N_\text{A}e$ | 96 485,33 C mol⁻¹ |
| Tetapan Planck | *h* | $6{,}626\,070\,15 \times 10^{-34}$ J s (tepat) |
| Laju cahaya | *c* | 299 792 458 m s⁻¹ (tepat) |
| Percepatan gravitasi standar | *g* | 9,806 65 m s⁻² (tepat) |
| Satuan massa atom | u | $1{,}660\,539 \times 10^{-27}$ kg |

| Besaran | Faktor konversi |
|---|---|
| Suhu | $T/\text{K} = \theta/{}^\circ\text{C} + 273{,}15$ |
| Tekanan | 1 bar = $10^5$ Pa; 1 atm = 101 325 Pa = 1,013 25 bar = 760 torr; 1 torr ≈ 1 mmHg = 133,322 Pa |
| Volume | 1 L = 1 dm³ = $10^{-3}$ m³; 1 mL = 1 cm³ |
| Energi | 1 L atm = 101,325 J; 1 L bar = 100 J; 1 cal = 4,184 J (tepat); 1 eV = $1{,}602 \times 10^{-19}$ J = 96,485 kJ mol⁻¹ |
| Kondisi acuan | tekanan standar $p^\circ$ = 1 bar; STP lama: 0 °C, 1 atm; SATP: 25 °C, 1 bar |
| Hasil kali berguna | *RT* pada 298,15 K = 2,479 kJ mol⁻¹ = 24,79 L bar mol⁻¹; $RT\ln10$ pada 298,15 K = 5,708 kJ mol⁻¹ |
